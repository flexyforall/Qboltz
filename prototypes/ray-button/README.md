# Кнопка «Talk to us» с лучом — прототип

Раскадровка: [Figma, «Button - hover-animation» (968:754)](https://www.figma.com/design/oJQYEBb5q5ecyGu5tN6wfW/Qboltz?node-id=968-754).
Демо: `index.html`. Открывать через локальный сервер, например `npx serve .` из корня репозитория, затем `/prototypes/ray-button/`.
На странице есть ползунок, чтобы прокрутить анимацию вручную и сверить с кадрами 1–3.

## Как работает

- **Покой:** кадр 1. Луч лежит слева, из-за левого края кнопки.
- **Наведение (или фокус с клавиатуры):** луч один раз пролетает слева направо, примерно 1,3 с.
  - В середине, за текстом, — вспышка (кадр 2).
  - В конце луч гаснет справа (кадр 3) и снова проявляется слева, ещё 0,5 с.
- **Текст во время вспышки:** темнеет так же, как в кадре 2 (градиент `#000 → #CEB5EE`). Затемняется только та часть текста, над которой сейчас вспышка, и только настолько, насколько вспышка сильная.
- **`prefers-reduced-motion`:** анимация не проигрывается.

Слои взяты из Figma:
- заливка кнопки — радиальные градиенты;
- статичное фиолетовое свечение;
- картинка блика (`assets/flare-mask.png`), она работает маской поверх размытого белого эллипса.

JS только двигает луч и меняет его размер. Положения в кадрах 1–3 совпадают с раскадровкой.

## Вариант 1 (рекомендую): код

Весит около 40 КБ, чёткий на ретине и при любом масштабе. Вспышка и тёмный текст всегда синхронны: тёмный текст считается от положения луча.

**Webflow**
1. Загрузить `assets/flare-mask.png`, `assets/plus.svg`, `assets/plus-dark.svg` в Assets. Заменить пути в CSS и HTML на ссылки Webflow.
2. Содержимое `ray-button.css` — в Page settings → Custom code → Head, внутрь `<style>`. Или в Embed.
3. Разметку кнопки из `index.html` (`<a class="ray-btn" data-ray-button>…</a>`) — в элемент Embed. Ссылку `href` поменять на нужную.
4. `ray-button.js` — в Custom code → Before `</body>` внутрь `<script>`.

**Режимы**
- По умолчанию — проигрывание на ховере.
- `data-ray-mode="loop" data-ray-interval="3500"` — луч пролетает сам каждые N мс.

**Если кнопка появляется после загрузки страницы** (CMS, табы), вызвать `RayButton.init()`.

Шрифт — Host Grotesk 400, 24px, межбуквенный 3.84px, uppercase.

**Поддержка**
- `mix-blend-mode: plus-lighter`: Chrome, Edge, Safari 15.4+, Firefox 104+.
- В старых браузерах луч просто ляжет без сложения цветов.

## Вариант 2: видео

`video/ray-bg.mp4` и `video/ray-bg.webm`:
- 876 × 296 — это 2× от кнопки 438 × 148, для ретины;
- 2 с, 30 fps;
- без текста, углы прямые.

Скругление 8px и текст делаются в HTML поверх видео.

```html
<a class="ray-btn-video" href="#">
  <video muted playsinline preload="auto" poster="ray-bg-first-frame.jpg">
    <source src="ray-bg.webm" type="video/webm" />
    <source src="ray-bg.mp4" type="video/mp4" />
  </video>
  <!-- светлый текст + тёмная копия поверх -->
</a>
```

**Запуск:** на `mouseenter` выставить `video.currentTime = 0`, затем `video.play()`.

**Тёмный текст** — отдельная CSS-анимация той же длины (2 с), запускается вместе с видео:

```css
@keyframes ray-dark-text {
  0%, 15%   { opacity: 0; }
  25%       { opacity: .43; }
  30%       { opacity: .88; }
  32.5%     { opacity: 1; }
  35%       { opacity: .88; }
  40%       { opacity: .43; }
  50%, 100% { opacity: 0; }
}
```

**Минусы видео**
- При первом ховере может быть задержка, пока видео загрузится и раскодируется.
- Текст затемняется целиком, а не по ходу вспышки.
- Тёмный текст может разойтись с видео на кадр.
- В Safari на iOS видео без звука играет только с `muted playsinline`.

`video/ray-button-preview.mp4` — превью кнопки целиком с текстом, для согласования.
