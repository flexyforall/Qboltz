# Кнопка «Talk to us» с лучом

Раскадровка: [Figma, «Button - hover-animation» (968:754)](https://www.figma.com/design/oJQYEBb5q5ecyGu5tN6wfW/Qboltz?node-id=968-754).
Ссылка на прототип для разработчика: https://claude.ai/artifact/REZRZ7zhzEcjMa6qfx9NDb
Архив для передачи: `ray-button-kit.zip`. Демо в репозитории: `index.html`. Открывать через локальный сервер, например `npx serve .` из корня репозитория, затем `/prototypes/ray-button/`.

## Поведение

- **Покой:** кадр 1. Луч лежит у левого края.
- **Когда кнопка появляется на экране** (видна на 60%), через 0,3 с луч один раз пролетает слева направо, примерно 1,3 с.
  - В середине, за текстом, — вспышка (кадр 2).
  - Потом луч гаснет справа (кадр 3) и тихо возвращается в кадр 1, ещё 0,5 с.
  - Весь проход длится 1,8 с.
- **Повтор:** каждый раз, когда кнопка уходит с экрана и возвращается. С `data-ray-once` — только в первый раз.
- **Ховер** луч не трогает: на ховер ставится отдельная анимация букв.
- **Текст во время вспышки** темнеет в градиент из кадра 2 (`#000 → #CEB5EE`). Затемняется только та часть текста, над которой вспышка.
- **`prefers-reduced-motion`:** анимация не проигрывается.

## Вариант 1: код

Файлы:
- `ray-button.html` — разметка;
- `ray-button.css` — стили;
- `ray-button.js` — анимация;
- `assets/flare-mask.png` — картинка блика из Figma, 37 КБ.

**Webflow**
1. Загрузить `assets/flare-mask.png` в Assets. В `ray-button.css` заменить `url("assets/flare-mask.png")` (2 места) на ссылку Webflow.
2. `ray-button.css` — в Site/Page settings → Custom code → Head, внутрь `<style>…</style>`.
3. `ray-button.html` — в элемент Embed на месте кнопки. Поменять `href`.
4. `ray-button.js` — в Custom code → Before `</body>`, внутрь `<script>…</script>`.

Шрифт — Host Grotesk 400, 24px, межбуквенный 3.84px, uppercase.

**Атрибуты на кнопке**

| Атрибут | Что делает |
|---|---|
| `data-ray-mode="inview"` | по умолчанию: проход при появлении на экране |
| `data-ray-once` | только в первый раз |
| `data-ray-delay="300"` | пауза после появления, мс |
| `data-ray-mode="loop"` + `data-ray-interval="3500"` | сам каждые N мс |
| `data-ray-mode="manual"` | только из JS: `el.rayButton.play()` |

**Если кнопка добавляется на страницу позже** (CMS, табы), вызвать `RayButton.init()`.

Работает в Chrome, Edge, Safari 15.4+, Firefox 104+ (нужен `mix-blend-mode: plus-lighter`).

## Вариант 2: видео

Файлы в `video/`, все без текста и плюса, углы прямые:

| Файл | Размер | Для чего |
|---|---|---|
| `ray-bg-876x296.mp4` / `.webm` | 2× | основной, чёткий на ретине |
| `ray-bg-438x148.mp4` / `.webm` | 1× | если нужен лёгкий вариант |
| `ray-bg-poster-*.jpg` | | первый кадр, он же состояние покоя |

- Длина 1,8 с, 60 fps.
- Первый и последний кадры совпадают — состояние покоя.
- `ray-button-preview.mp4` — превью целиком, с текстом, для согласования.

Готовый сниппет — `video-embed.html` (разметка, стили и скрипт в одном Embed):
- видео лежит фоном под HTML-текстом;
- скругление 8px делается обёрткой;
- видео проигрывается с начала при появлении кнопки на экране;
- по желанию текст темнеет во время вспышки CSS-анимацией в такт видео.

Минусы видео по сравнению с кодом:
- на первом показе может быть задержка, пока видео загрузится;
- текст затемняется целиком, а не по ходу вспышки;
- нечёткость при масштабе больше 2×.
